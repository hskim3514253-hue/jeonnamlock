# 상품 자료와 사용 범위

확인일: 2026-10-22. 현재 6개 브랜드 23개 모델을 제조사 공개 자료에서 개별 조사했다. 키넷의 전체 상품 데이터베이스를 복제한 목록이 아니며 재고·공식 대리점·즉시 설치 가능 여부를 보장하지 않는다. 모든 상품은 가격문의이고 기존 지정 제품 가격표와 별도다.

## 사진과 설명

- 제품 이름·인증 방식·규격은 제조사 자료의 사실을 확인하고 설명은 새로 작성했다. 각 제품의 공식 출처와 확인일은 `src/catalog.mjs`, `src/catalog-manufacturers.mjs`에 기록한다.
- 키넷 상품 사진, 상세페이지 이미지, 광고 문안은 복제하지 않는다. 기존 아카라 제품 사진도 재게시 허락이 확인되지 않아 이번 공개 카탈로그에서 제외했다. 사진은 공식 제품 페이지로 연결한다.
- 화면의 선 그림은 자체 제작한 유형 안내이며 실제 제품 사진이 아님을 표시한다.
- 사진을 추가할 때에는 소유권 또는 상업적 재게시 허락을 확인하고 `mediaPermission: 'owner' | 'licensed'`, 이미지별 `rightsSource`에 내부 승인 근거를 남긴다. 비밀값·개인정보·계약 원문은 코드에 넣지 않는다.
- 키넷의 전체 416개 상품 이전은 진행하지 않았다. [키넷 약관 제22조](https://keynet.kr/member/agreement.html)의 이용 제한과 데이터베이스 권리를 고려해 사전 이용 허락을 받아야 한다. 공개 사양 자체와 전체 데이터베이스 복제 권한은 구별한다.

## 원본 영상

- K100: [공식 TV 광고](https://www.youtube.com/watch?v=vKfQLjVWjpo). [아카라 공식 제품 소개](https://docs.aqaralife.kr/ko/articles/제품-소개-dabf18fd)에서도 같은 영상을 사용한다.
- L100: [공식 허브 연결 안내](https://www.youtube.com/watch?v=HHQPZkHHNW8). 아카라 라이프 공식 채널 영상이며 광고가 아닌 사용 안내로 표시한다.
- 두 영상 모두 원본 YouTube 플레이어만 사용하며 다운로드·재업로드·광고 제거를 하지 않는다. 클릭할 때만 youtube-nocookie.com iframe을 로드한다. 원본 링크를 항상 함께 제공한다.
- [YouTube 공식 삽입 안내](https://support.google.com/youtube/answer/171780?hl=ko)에 맞춰 Referer를 유지한다. 외부 소유자가 삽입을 차단하거나 영상을 삭제하면 원본 링크로 안내한다.

## 추가 상품 등록

1. 제조사 자료 또는 공급업체가 사용 허락한 자료에서 정확한 모델별 사실을 확인한다.
2. `src/catalog-manufacturers.mjs`에 브랜드·카테고리·설명·사양·공식 URL을 추가한다. 브랜드와 분류 필터는 자동 생성된다.
3. 데이터가 없는 기능, 사진, 설치 조건, 보증·재고 정보는 추정하지 않는다.
4. `node scripts/build.mjs`와 관련 테스트를 실행한 후 배포한다. 목록은 12개씩 나눠 표시하며 검색·필터는 전체 제품에 적용된다.
