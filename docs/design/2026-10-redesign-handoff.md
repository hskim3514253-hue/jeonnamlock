# 전남열쇠 홈페이지 개편과 방문 통계

기존 공개 홈페이지의 주소, 지정 제품 가격, 별도 사진 견적, 사장님 접수함과 Web Push 알림을 유지하면서 고객 화면을 아이보리와 네이비로 개편했다. 시간별 방문 통계는 사장님 관리의 새 탭에서 제공한다.

## 디자인 원본과 적용 범위

- Lovable 초안: https://lovable.dev/projects/9aca3b43-597e-4087-86eb-15b067822b31
- 확인한 초안 커밋: `eff00ddc63188eab1585f97990d5adaaa6514b3e`. 생성 상태와 응답 완료를 확인하고 홈 소스, 가격과 별도 견적 문구, 도구 제공 데스크톱 이미지를 검토했다. 초안은 공개 배포하지 않았다.
- Figma 파일: https://www.figma.com/design/x6FqkmLUj7S2UObfXQSGJ8
- Figma 상태: **미완성**. 파일 생성과 Simple Design System의 Button/Input Field 가져오기까지만 완료했다. 이후 Starter 플랜 MCP 한도로 작업이 차단됐다. 고객 홈과 통계의 네 화면은 아직 작성되지 않았다.
- 2026년 10월 8일 사용자가 “홈페이지부터 완성해줘”라고 승인하여 Figma 작업을 보류하고 Lovable의 승인된 시각 방향으로 운영 사이트 구현을 진행했다. 자동 재개 일정이나 유료 전환은 설정하지 않았다.

초안의 큰 한글 제목, 편집 지면 같은 간격, 선으로 구분된 가격표, 두 상담 버튼을 적용했다. 사이트의 동작을 보존하기 위해 기존 단일 페이지와 세 단계 폼을 유지한다. 한국어 글꼴은 기존에 사용하는 Pretendard를 유지했고, 이미 검증된 도어락 연출 이미지를 재사용했다. 실제 시공 사진으로 표시하지 않는다. 후기는 네이버 원문으로 연결한다.

## 통계 정의와 운영

- `/admin#analytics`에서 사장님 계정으로 확인한다. 기본 날짜는 서버의 한국 날짜다.
- 하루 방문자는 당일 중복을 제거한 브라우저 추정치다. 시간별 방문자는 각 시간 안에서 중복을 제거하며 하루 합계와 단순 합산이 일치할 필요는 없다.
- 페이지 조회는 첫 표시, 새로고침, BFCache 복원이다. 앵커 이동과 폼 단계 변경은 세지 않는다.
- 서명된 당일 HttpOnly 쿠키를 사용한다. 쿠키 차단·삭제, 다른 기기와 최초 여러 탭은 추정 오차를 만들 수 있다.
- 고객 정보, 사진, 원시 IP, 전체 User-Agent, URL 쿼리를 통계에 저장하지 않는다.
- 적용 후부터 수집하고 최근 90일을 보관한다. 오류·수집 전·미래 시간은 0건과 구별한다. 자동 갱신 대신 새로고침으로 확인한다.

## 확인한 동작

- 1440px 및 390px 화면의 가격표·별도 견적·전화 버튼과 전체 페이지 가로 넘침 없음.
- 로컬 실제 SQLite에서 첫 방문, 재방문, 시간 경계, 한국 자정, 중복 재전송, 동시 중복, 쿠키 변조, 보관 정리와 재실행 후 유지.
- 관리자/봇 제외, 비로그인 401, 다른 계정 403, 외부 출처 403, 큰 본문과 잘못된 날짜 차단.
- 관리자 직접 진입과 로그인 요구, 24행 시간표, 미래 시간, 빈 데이터, 수집 전, 오류 시 수치 숨김, 지연 시 로딩과 재시도.
- 통계 패널 오류에도 견적 접수함과 무료 알림 설정은 동작.
- 문 사진을 첨부한 로컬 문의의 접수번호 발급. 통계 수집 API가 503인 별도 로컬 서버에서도 제품 사진을 첨부한 문의의 접수번호 발급.
- 모든 시험 고객 정보와 사진은 무시되는 로컬 검증 저장소에만 존재하며 배포물에 포함하지 않는다.

최종 독립 코드 검토에서 발견한 날짜 재시도와 오류 안내 두 건을 수정했다. 실패한 과거 날짜와 오늘 조회의 재시도 의도를 유지하고, 잘못된 날짜·미래 날짜·90일 이전 날짜의 안내를 구분한다. 수정 전 회귀 테스트 실패를 확인하고 수정 후 전체 28개 테스트 통과를 확인했다.

브라우저 단위 방문 추정치의 한계는 관리자 화면에 표시한다. 모든 봇 차단이나 사람 단위 식별은 제공하지 않는다. 기존 무료 알림의 서버 회귀 테스트는 통과했으나 이번 개편에서 실제 휴대폰 수신 시험을 새로 실행한 것은 아니다. 배포 성공 여부는 Sites 배포 결과로 확인한다. Figma 원본 완료 또는 Lovable 미리보기의 직접 모바일 검증을 이 문서가 주장하지 않는다.
