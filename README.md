# 전남열쇠 홈페이지

반응형 고객 홈페이지와 Cloudflare Workers 기반 견적 접수 서버입니다. 고객의 설치 동네·연락처·선택한 제품 정보를 D1에, 필수 문 사진과 선택 제품 사진을 비공개 R2에 저장합니다. 새 양식은 성함과 상세 주소를 수집하지 않습니다. `/admin`에서 사장님 계정으로 조회하고 상담 상태를 변경할 수 있습니다.

## 실행과 검증

- Node.js 24 이상, pnpm 11 사용
- `pnpm install --frozen-lockfile`
- `pnpm test`: 실제 SQLite와 로컬 파일 저장소를 사용하는 서버 통합 테스트
- `pnpm build`: 정적 파일을 포함하는 단일 Worker `dist/server/index.js` 생성
- `node preview-server.mjs`: `http://127.0.0.1:4173`에서 개발 실행

개발용 데이터는 무시되는 `.local-data/`에만 저장됩니다. 로컬 로그인은 개발 서버에서만 제공하며 배포 Worker에는 포함되지 않습니다. `.env.example` 값은 개발 예시이고 운영 값으로 사용하면 안 됩니다.

## 운영 설정

Sites에서 D1 `DB`와 R2 `BUCKET`을 연결합니다. Drizzle 마이그레이션은 `drizzle/`에 있으며 배포 아카이브의 `.openai/drizzle/`에 포함해야 합니다. 운영 마이그레이션을 적용한 뒤에는 기존 SQL을 수정하지 않고 새 마이그레이션을 추가합니다.

운영 환경 변수:

- `SITE_ORIGIN`: 배포 홈페이지의 HTTPS 원점
- `ADMIN_USER_IDS`: 플랫폼이 주입한 `oai-authenticated-user-id`의 쉼표 구분 허용 목록. 이메일이나 브라우저가 제출한 값을 권한 판단에 사용하지 않습니다. 미설정 시 관리자 접근을 차단합니다.
- `RATE_LIMIT_SALT`: 임의의 비밀값
- `CONFIG_ENCRYPTION_KEY`: 32바이트를 표현하는 64자리 16진수 비밀값. 푸시 구독 주소 암호화에 사용하므로 운영 중 임의 변경하지 않습니다.
- `VAPID_PUBLIC_KEY`: 브라우저 푸시 구독에 사용하는 P-256 공개키(base64url)
- `VAPID_PRIVATE_JWK`: P-256 ECDSA 개인키 JWK JSON. Sites 비밀값에만 저장합니다.

알림은 `/admin#notifications`에서 활성화합니다. 아이폰(iOS 16.4 이상)은 Safari의 공유 메뉴에서 **홈 화면에 추가**하고, **웹 앱으로 열기** 옵션이 있으면 켜세요. 홈 화면에 생긴 전남열쇠 아이콘으로 실행한 뒤 사장님 계정으로 로그인하고 **무료 알림 설정 → 이 아이폰에서 무료 알림 켜기 → 허용**을 선택합니다. **휴대폰 알림 수신 시험**으로 실제 도착을 확인하세요. 알림이 차단됐다면 아이폰의 설정 → 알림에서 추가한 웹앱의 알림을 허용해야 합니다. 안드로이드의 기존 Chrome 알림도 지원합니다.

Web Push(RFC 8030)와 VAPID(RFC 8292)를 사용하므로 별도 문자 서비스 가입이나 건당 문자 요금이 없습니다. 홈페이지 호스팅·저장소 비용은 별개입니다. 고객 정보가 없는 빈 푸시를 보내고 서비스 워커가 고정 안내를 표시합니다. 알림에는 고객 이름·전화번호·주소·사진을 포함하지 않습니다. 기기의 푸시 구독 주소는 AES-GCM으로 암호화하고 허용된 푸시 서비스 호스트로만 전송합니다. 최대 5대 기기를 등록할 수 있습니다.

견적과 발송 대기 기록을 먼저 저장하므로 알림 실패로 문의가 사라지지 않습니다. 발송 요청 완료는 푸시 서비스의 접수 상태이며 휴대폰 도착을 보장하지 않습니다. 접수 즉시 발송을 요청하지만 네트워크·방해금지·절전·브라우저 강제 종료로 늦어질 수 있습니다. 대기·실패 건은 관리자 화면에서 최대 10건씩 다시 요청합니다. 만료된 구독은 비활성화하며 해당 기기에서 알림을 다시 켜야 합니다. 알림 활성화 이전 문의는 접수함에서 확인할 수 있지만 과거 알림을 소급 발송하지 않습니다. 서비스 워커는 고객 페이지나 API를 캐시하지 않습니다.

기존 문자 기능은 실행 코드와 관리 화면에서 제거했습니다. 이미 적용된 DB 마이그레이션의 `settings`/`sms_outbox` 테이블은 마이그레이션 이력을 보존하기 위해 남겨두며 신규 데이터는 기록하지 않습니다.

## 데이터와 접근

- 새로고침 후에도 서버 데이터가 유지되며 브라우저 저장소를 고객정보 원본으로 사용하지 않습니다.
- 새 양식은 문 사진 최소 1장, 최대 5장을 요구합니다. 기존 양식으로 작성 중이던 문의는 기존 동의 버전으로 재시도할 수 있습니다. 이름·주소 DB 열은 기존 이력을 위해 유지하되 새 문의에는 빈 값만 저장합니다.
- 업로드당 최대 10MB, 문/도어락 각각 최대 5장. JPG·PNG·WEBP의 MIME 및 파일 시그니처를 검사합니다.
- 접수 토큰과 요청 키로 재전송 중복을 방지합니다. 서버에서 모든 첨부 파일 존재를 확인한 뒤 접수 번호를 발급합니다.
- 관리 API와 사진 조회는 사장님 사용자 ID를 검사하고 캐시를 금지합니다.
- 임시 작성 건은 24시간 후 접근을 차단하고 이후 접수/관리 화면 조회 시 순차 정리합니다. 별도 주기 실행 작업은 없습니다.
- 접수한 문의는 상담 완료 시 **상담 완료 · 정보 삭제**로 고객 정보와 첨부 사진을 삭제합니다. 삭제는 복구되지 않으므로 실제 상담이 끝난 뒤 처리합니다.
- 동일 접속 주소의 신규 접수는 시간당 10건으로 제한합니다. 공개 운영 중 공격이 발생하면 추가 봇 차단과 사용량 제한이 필요할 수 있습니다.

## 공개 운영 전 사업자 확인

2026년 9월 28일 소유자 요청으로 일반 고객에게 공개했습니다. 관리자 API와 고객 사진은 허용된 사장님 계정으로만 조회할 수 있습니다. 사장님 휴대폰에서 알림을 허용하고 실제 수신 시험을 완료하세요. 개인정보 안내의 사업자 연락처, 처리위탁·국외처리 관련 고지, 실제 보관·삭제 업무를 운영 상황과 맞춰 확정해야 합니다. 이 구현 자체가 법적 적합성 검토나 가용성 보장을 대신하지는 않습니다.

사이트에는 결제·온라인 주문·확정 견적 기능이 없고 상담 요청을 접수합니다. 수집된 고객 정보는 관리자 화면에서만 취급하세요. 저장소 사용량과 알림 실패 내역을 정기적으로 확인하세요.

## 검색엔진 설정

홈페이지는 가격표와 견적 안내를 원본 HTML로 제공합니다. 대표 URL은 `https://jeonnam-lock-studio.hskim3514253.chatgpt.site/`이며 `/index.html`은 쿼리를 유지하여 `/`로 301 이동합니다. 제목·설명, canonical, Open Graph 텍스트, 실제 업체 정보를 담은 Locksmith JSON-LD와 네이버 소유 확인 태그를 포함합니다. 구조화된 데이터에는 별점이나 실제 모델이 확정되지 않은 상품 가격을 넣지 않습니다.

`/robots.txt`와 `/sitemap.xml`을 빌드에 포함합니다. 사이트맵에는 공개 홈페이지만 등록하며, 관리자 화면과 API에는 검색 제외 응답 헤더를 적용합니다. 검색 제외는 접근 제어를 대신하지 않으며 기존 관리자 인증을 유지합니다. 도메인이 변경되면 메타데이터·구조화된 데이터·사이트맵·robots의 주소를 함께 수정해야 합니다. 홈페이지 내용이 실제로 변경된 경우에만 사이트맵의 `lastmod`를 갱신합니다.

## 방문 통계

`/admin#analytics`에서 사장님 계정으로 날짜별 방문자, 페이지 조회, 24시간 차트와 표를 확인합니다. 모든 날짜는 서버의 한국 시간 기준이며 기본값은 오늘입니다. 화면은 새로고침으로 갱신됩니다.

`analytics_events`와 `analytics_state`만 새로 추가하는 마이그레이션 `0004`를 배포합니다. 기존 견적·사진·푸시 데이터와 비밀값은 변경하지 않습니다. 통계 수집은 R2 가용성과 독립적이고 실패해도 견적 폼을 막지 않습니다. 통계가 필요하면 배포된 DB의 새 마이그레이션 성공 여부를 확인하세요.

당일 서명된 HttpOnly 쿠키 `__Host-jn-visit`로 브라우저를 구분하며 한국 자정에 만료됩니다. 저장 데이터는 임의 이벤트 ID, 날짜, 시간, 당일 식별자의 HMAC, 서버 수신 시각입니다. 개인정보나 원시 IP를 통계에 저장하지 않습니다. IP 해시는 120회/분 요청 제한에만 사용하며 짧은 만료 후 일일 정리합니다. 쿠키 차단·삭제나 다른 브라우저에서는 방문자 오차가 생깁니다. 로그인 관리자와 식별 가능한 봇은 제외합니다.

하루와 시간별 중복을 각각 제거하므로 시간별 방문자 합계가 하루 방문자와 다를 수 있습니다. 페이지 조회에는 새로고침·뒤로가기 복원이 포함되며 광고 클릭 수가 아닙니다. 기록은 적용 이후부터이며 오늘을 포함한 90일 범위 밖 데이터는 다음 통계 수집 또는 조회 때 정리합니다.

디자인 원본과 검증 범위는 [디자인 인계 문서](docs/design/2026-10-redesign-handoff.md)를 참고하세요. Figma 편집 원본은 플랜 한도로 미완성이며 사용자 승인에 따라 홈페이지 구현을 먼저 진행했습니다.

## 첫 화면 스크롤 연출 (2026-11-17, 저장본 · 운영 미배포)

홈페이지 맨 위 `lock-intro` 섹션은 검은색 푸시풀 도어락이 스크롤에 따라 입체로 회전·확대된 뒤 가까이 잡은 현관문에 결합되고 오른쪽에 소개 문구가 나타납니다. `dist/intro.css`, `dist/intro.js`, `dist/intro-lock.png`, `dist/intro-door.jpg`로 구성하며 `scripts/build.mjs`와 `preview-server.mjs`의 공개 파일 목록에 등록했습니다.

- 두 이미지는 Figma AI(gpt-image-2.5-sunburst)로 생성한 연출 이미지이며 실제 제품·시공 사진이 아닙니다. 화면에 그 사실을 표기합니다. 특정 브랜드 제품을 묘사하지 않습니다.
- 도어락은 앞면 사진 뒤에 얇은 판을 겹쳐 쌓아 본체와 손잡이의 두께를 만든 CSS 3D 모델입니다(WebGL·외부 라이브러리 없음). 옆면·뒷면은 사진이 아닌 단색입니다.
- 위치·회전은 스크립트가 CSSOM으로 지정하므로 인라인 스타일이 없고 CSP를 변경하지 않았습니다.
- 스크립트가 없거나 `prefers-reduced-motion`이 켜져 있으면 결합이 끝난 정지 화면으로 표시합니다.
- 도어락 위치 값(`intro.css`의 `.intro-lock`과 `intro.js`의 상수)은 문 사진 기준이므로 사진을 바꾸면 함께 조정합니다.

## 가격문의 채팅 (2026-11-17, 저장본 · 운영 미배포)

제품 카드와 상품 상세의 **가격문의** 버튼을 누르면 채팅창이 열리고 `POST /api/chat`이 그 제품의 가격을 답합니다. 화면은 `dist/chat.js`·`dist/chat.css`, 서버는 `src/chat.mjs`, 가격 자료와 답변 규칙은 `src/prices.mjs`입니다.

- **가격 자료**: `PRICE_TABLE`은 홈페이지 설치 가격표(지정 제품 · 설치비 포함)와 같은 값입니다. 모델별 확정 가격은 `PRODUCT_PRICES`에 제품 id로 넣습니다(현재 비어 있음). 확정 가격이 없는 모델에는 가격표 금액을 그 모델의 가격처럼 말하지 않고 별도 견적으로 안내합니다. 가격표를 바꾸면 홈페이지 가격표와 `PRICE_TABLE`을 함께 고칩니다.
- **AI 답변**: 환경변수 `ANTHROPIC_API_KEY`가 있으면 Claude(Messages API, 기본 `claude-opus-5-5`, `CHAT_MODEL`로 변경 가능)가 위 자료만 근거로 답합니다. 키가 없거나 호출이 실패·거절되면 같은 자료로 만든 고정 문장으로 답하므로 버튼은 항상 동작합니다. 번들러 없는 단일 Worker라 SDK 대신 fetch로 호출합니다. 거절 시 자동 대체 모델(`fallbacks: "default"`)을 켰습니다.
- **보호**: 같은 접속 주소당 시간당 40회, 대화 12턴, 질문 500자로 제한합니다. 대화는 서버에 저장하거나 로그로 남기지 않습니다. 채팅창에 AI 답변이라는 점과 개인정보를 적지 말라는 안내를 표시합니다.
- **운영 전 확인**: API 키는 Sites 비밀값에만 넣습니다. 실제 키로 답변 품질을 시험하지 않았습니다. 질문 내용이 외부 AI 서비스(Anthropic, 국외)로 전송되므로 개인정보 처리방침의 처리위탁·국외이전 고지를 갱신해야 합니다. 사용량에 따라 API 요금이 발생합니다.

## 호스팅: Render + GitHub (2026-11-17 전환 준비, 아직 운영 전환 전)

소유자 요청으로 ChatGPT Sites를 떠나 GitHub 저장소와 Render 웹 서비스로 옮깁니다. `render.yaml`(Blueprint)이 서비스를 정의하고, `main` 브랜치에 푸시하면 Render가 자동 배포합니다.

- **서버**: `server.mjs`가 Cloudflare Worker와 같은 요청 처리기(`src/worker.mjs`)를 Node에서 실행합니다. DB는 SQLite, 고객 사진은 파일로 Render 영구 디스크(`/var/data`)에 저장합니다. 디스크가 없으면 재배포 때 문의가 사라지므로 유료 인스턴스(starter)와 디스크가 필요합니다.
- **빌드/실행**: `node scripts/prepare.mjs` → `node server.mjs`. 설치할 패키지는 없습니다. Node 24 이상(`node:sqlite`).
- **관리자 로그인**: ChatGPT 계정 대신 비밀번호입니다(`src/password-login.mjs`, `/admin/login`). 서버가 비밀번호를 확인하고 서명된 HttpOnly 쿠키(30일)를 줍니다. 같은 주소에서 15분에 8번 틀리면 잠깁니다. 비밀번호를 바꾸면 모든 기기에서 로그아웃됩니다.
- **환경변수**: `ADMIN_PASSWORD`(10자 이상, 소유자가 Render 대시보드에 직접 입력), `SESSION_SECRET`·`RATE_LIMIT_SALT`·`CONFIG_ENCRYPTION_KEY`(Render가 자동 생성), `SITE_ORIGIN`(도메인 전환 후 `https://jeonnamlock.com`; 비우면 Render 주소), `DATA_DIR`, 선택 `ANTHROPIC_API_KEY`·`CHAT_MODEL`. Web Push 키는 첫 실행 때 만들어 디스크에 보관합니다.
- **데이터**: Sites의 기존 문의·사진·푸시 구독은 옮기지 않고 새로 시작합니다. 전환 전에 기존 접수함을 처리해야 합니다.
- **도메인**: Render에 `jeonnamlock.com`을 사용자 도메인으로 추가한 뒤 가비아 DNS의 A 레코드를 Render가 안내하는 값으로 바꿉니다. 네임서버 변경은 필요 없습니다.
- `cloudflare/`, `wrangler.jsonc`, `src/access.mjs`는 Cloudflare 계정으로 옮기는 대안으로 만들어 둔 것이며 Render에서는 쓰지 않습니다. `scripts/build.mjs`와 `.openai/`는 이전 Sites 배포용입니다.
